# Chess Games

Static web app featuring all chess events I ever took part in.

Built with :heart: using [Gatsby](https://www.gatsbyjs.org/).

Visit and watch my games [here](https://chess.rui-alves.me) (deployed using [Netlify](https://www.netlify.com/)).

## Project setup

To setup the project, install dependencies:

```
npm install
```

To access other infos, use the [Official Gatsby Documentation](https://www.gatsbyjs.org/docs/).
